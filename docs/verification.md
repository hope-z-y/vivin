# 首版验证记录

## 已验证

- macOS Apple Silicon：`pnpm check`、`pnpm build`、`cargo fmt --check`、`cargo check`、`cargo test`、`pnpm tauri build --bundles app`。
- 原生窗口：创建和打开项目、文档与目录操作、原文及排版编辑、自动保存、全文搜索、术语、标注、缩略图、双栏同步、锁定只读、外部修改冲突与重新加载、资源库展开、项目内相对路径图片和 GFM 表格显示。本轮另用两个独立测试项目确认项目名称下拉菜单可直接切换；固定资源库可展开子目录并按文件递归计数；排版与原文两种视图选中文字后均出现四类浮层标注操作，实际创建待办后计数由 0 变为 1；中英文和明暗模式切换已在原生窗口检查。
- 顶部右侧“+”菜单的新建和打开项目入口、插画式空状态、无装饰性边框的文档排版与深色模式已在更新后的窗口核对；搜索、术语、标注和修改记录的空状态，以及加载提示已通过前端构建与类型检查。
- 本机 MCP：读取项目规则与文档、写入已打开文档、双栏即时同步、记录 AI 修改与撤销。
- 项目路径边界：Rust 测试覆盖越界路径、符号链接文档和受管理目录的符号链接。

## 平台与发布状态

- 窗口使用 Tauri 无边框配置，应用内提供拖动区域及窗口控制。
- Windows x64 的 NSIS 构建已配置在 `.github/workflows/desktop-build.yml`，但尚未运行 Windows 构建与实机验收。
- 当前 macOS 包未使用 Apple Developer ID 签名与公证。对外分发前需要补齐签名、公证和 Windows 签名，并在两种系统上做安装、升级及卸载验收。

## 已知限制

- 排版编辑器遇到不能保持语义的 Markdown 时会回退到原文模式，避免丢失原文内容。
- 首版限制为左右两栏；资源文件只列出路径和类型，不解析内容。
- 本机 MCP 仅在 vivin 运行时可用，监听 `127.0.0.1:38419`。端口被占用时应用仍可编辑，但 MCP 无法启动；需释放端口后重启应用。
