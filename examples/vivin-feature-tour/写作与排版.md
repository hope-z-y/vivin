# 写作与排版

这篇文档展示 vivin 当前支持的常用 Markdown。你可以在顶部切换**排版**和*原文*，然后继续编辑。

## 段落、链接与引用

星图计划是一份用于演示的虚构写作项目。每个项目都是一个本地文件夹，正文保持为普通 `.md` 文件。Markdown 的 [语法说明](https://www.markdownguide.org/basic-syntax/) 可作为外部参考。

> 好的写作工具让内容、来源资料和评论各归其位。

## 列表与任务

1. 创建项目并添加文档。
2. 写下内容，切换原文与排版视图。
3. 为需要讨论的位置添加标注。

- [x] 完成项目结构
- [x] 添加示例附件
- [ ] 试着勾选这个 Markdown 任务项

上面的任务列表属于**正文**；左下角的“待办”数量统计的是独立标注，两者互不混用。

## 代码与表格

```ts
type Note = { title: string; done: boolean };
const note: Note = { title: '星图计划', done: false };
```

| 格式 | 在排版视图中       | 在原文视图中       |
| ---- | ------------------ | ------------------ |
| 标题 | 分级标题           | `#`、`##`          |
| 列表 | 有序、无序和任务项 | 普通 Markdown 语法 |
| 图片 | 项目内相对路径     | `![说明](路径)`    |

## 图片附件

下图保存在项目的 `attachments/` 中，Markdown 使用相对路径。你也可以在编辑器中粘贴或拖入自己的 PNG、JPEG、GIF、WebP 图片。

## 自动保存

修改正文后等待自动保存，再切到原文查看磁盘上的 Markdown。工具区没有额外的“保存”按钮；如果外部程序同时修改了文件，应用会提示你处理冲突。
