# vivin 功能导览

欢迎来到这个可直接打开的演示项目。项目文件夹包含 Markdown 文档、附件、`resources/`、项目规则和 `.vivin/` 数据；复制整个文件夹后，这些内容会一起移动。

> 建议先复制这份演示项目，再在副本里练习改名、移动、删除与撤销。直接修改仓库中的示例也可以，但会让 Git 显示改动。

## 先看这些功能

| 想看什么            | 怎么做                                                               |
| ------------------- | -------------------------------------------------------------------- |
| 项目切换            | 点击顶部项目名，再选最近项目或打开另一个文件夹                       |
| 新建项目            | 点击顶部右侧的 `+`                                                   |
| 项目文件树          | 展开左侧的 `项目管理/` 和 `练习区/`                                  |
| 固定文档            | 看 `项目管理/固定在前面的文档.md`，也可右键其他文档切换固定          |
| 直接与继承锁定      | 分别打开 `直接锁定.md` 与 `继承锁定/只读说明.md`                     |
| 资源库              | 展开左侧 `resources`，查看 TXT、CSV、JSON 三种文件；内容不进入搜索   |
| Markdown 排版与原文 | 打开 `写作与排版.md`，切换顶部的排版／原文                           |
| 术语悬停            | 打开 `标注与术语.md`，悬停“项目快照”或“上下文锚点”                   |
| 四类标注            | 在 `标注与术语.md` 中点击正文标记、右侧位置点或左下角计数            |
| 标注浮层            | 在未锁定文档里选中文字，在浮层中选待办、批注、疑问或错误             |
| 全文搜索            | 搜索 `星图计划`，命中多个文档；再搜索资源 CSV 第一行的编号，应无结果 |
| 双栏查看            | 打开一篇文档后点击顶部分栏按钮，再在两栏打开同一篇文档               |
| AI 修改记录         | 打开顶部“更多”→“AI 修改记录”，查看可撤销的演示记录                   |
| Codex 本机接口      | 打开顶部“更多”→“Codex 连接信息”，查看本机连接配置文件路径            |
| 项目规则            | 打开顶部“更多”→“编辑项目规则”，查看根目录 `AGENTS.md`                |
| 中英文与明暗模式    | 使用顶部右侧的语言和主题按钮                                         |

## 需要亲手触发的状态

在 `练习区/` 右键新建文档和目录，试着重命名、移动、删除，再观察文件夹中的真实文件变化。删除演示内容前，先复制项目以便随时重来。

在同一篇未锁定文档的两栏中编辑，观察共享正文与各自的视图模式。为了体验冲突提示，可在 vivin 打开并修改文档时，用外部编辑器改动磁盘文件；请在项目副本中尝试。

需要试用 Codex 接口时，先在“Codex 连接信息”找到本机连接配置，连接后调用 `project_context` 读取本项目规则，再让 Codex 在 `练习区/` 创建或修改文档。成功写入会进入 AI 修改记录；若目标被锁定或版本已变化，应看到明确的拒绝原因。

空项目、搜索无结果、无术语和无标注的空状态，需要新建一个空项目或清空搜索条件才会出现。加载状态只在读取过程中短暂出现。Windows 与 macOS 的项目数据格式相同；这里的示例不依赖绝对路径。

## 说明

右侧目前是**标注位置栏**，展示大致分布和类型筛选，还不是全文内容缩略图。这个演示项目会让四种颜色的点分散在长文档中，便于观察当前实现。
