# vivin 功能演示项目写作规则

这是供 vivin 与本机 Codex 接口演示的项目。正文使用简体中文，标题清楚、段落简短，保留普通 Markdown 格式。

## 编辑约定

- 新内容放在 `练习区/`，或在现有文档末尾添加小节。
- 引用 `resources/` 中的资料时写明相对路径；资源文件仅供查阅，不作为正文搜索对象。
- 保留 `标注与术语.md` 中的演示短语，便于四类标注和位置缩略图展示。
- `项目管理/直接锁定.md` 和 `项目管理/继承锁定/只读说明.md` 用来演示锁定，请先在应用中解锁，再修改内容。
- 修改前读取项目规则和文档版本；发生冲突时停止写入并向用户说明。

## 术语

- 项目快照：复制整个项目文件夹后保留的文档、资源和结构化数据。
- 上下文锚点：用选中文本及其前后语境定位标注的方法。
- 位置缩略图：文档右侧显示标注大致分布的轻量标记栏。
