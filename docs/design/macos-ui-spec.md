# macOS 界面交互补充说明

本文件补充 [macOS 界面概念图](macos-ui-concept.png) 未展示的交互和状态。功能边界以 [需求文档](../requirements.md) 为准。概念图中的 `resources` 位置和术语卡片“在文档中查看”文案按本文调整，其余视觉风格沿用概念图。

## 左侧面板

- 从上到下依次为“项目文件”“资源库”和底部四类标注入口。资源库对应项目根目录的 `resources/`，不在“项目文件”树中重复出现。资源库可以展开子目录；文件行显示名称和类型，不显示预览或内容摘要。
- 项目文件树的文档和目录使用右键菜单提供创建、重命名、移动、删除、固定以及锁定操作；只对适用的对象展示对应命令。直接锁定用实心锁图标，继承上级锁定用浅色锁图标，悬停时说明来源目录。继承锁定的条目不能单独解锁。
- 底部“待办 / 批注 / 疑问 / 错误”的数字是当前项目内该类型的标注总数，包括已失去准确原文位置的标注。“待办”不包含 Markdown 任务列表。点击一项打开项目标注列表，并默认筛选该类型；列表显示文档、所选原文、说明和位置状态。点击可定位的标注跳到文档，无法定位的标注明确显示“需重新定位”。
- 项目切换时清空旧项目的搜索结果和标注列表，并刷新项目文件树、资源库与四类计数。

## 顶部工具栏与文档栏位

- 工具栏保留项目切换、当前项目搜索、原文／排版切换、分栏和“更多”。项目切换菜单提供“编辑项目规则”，打开项目根目录的 `AGENTS.md`。单栏时视图切换控件作用于唯一栏位；双栏时作用于最近激活的栏位，该栏位用轻量高亮表示。两栏可分别选择不同视图。
- 锁定文档只显示只读 Markdown 原文；文档顶部显示“已锁定”或“由〈目录名〉锁定”，原文／排版切换不可用，编辑、粘贴图片和标注操作不可用。其他未锁定栏位仍可正常编辑。
- 两栏打开同一文档时，两栏正文实时同步，选区和滚动位置各自保留。一个栏位修改正文后，另一个栏位的阅读位置尽量保持稳定；两栏看到的保存状态一致。
- 检测到磁盘外部修改时，在受影响的文档栏位显示持续可见的冲突提示，提供“重新加载磁盘版本”和“将当前内容另存为新文档”。解决前停止对原文件的自动保存；不要用提示自动消失表示问题已解决。
- 顶部“更多”提供“AI 修改记录”。记录面板按时间倒序展示操作、受影响的项目相对路径或数据项和变化内容；每条记录提供撤销操作。若目标被锁定或已有后续修改，显示明确原因并禁止覆盖。

## 术语与标注

- 术语悬停卡片展示当前悬停词对应的术语名和解释，两者必须一致；底部操作文案为“查看术语”。点击后打开项目术语列表并定位到该术语。术语解释不指向一篇专门的 Markdown 文档。
- 每个文档栏位的 minimap 顶部放置类型筛选按钮。菜单中四类标注可多选，并有“显示全部”；筛选只控制当前栏位 minimap 上的标记，不改变正文标记、标注列表或项目计数。两栏分别记住自己的筛选状态。
- 点击正文标记或 minimap 标记，定位到对应原文并打开标注详情；详情可编辑说明或删除标注。删除只移除标注数据，不修改 Markdown 正文。无法准确定位的标注保留在项目标注列表中等待用户处理，不在错误位置绘制 minimap 标记。

1. 把 `resources` 从“项目文件”树移到独立的“资源库”区域。
2. 为 minimap 增加类型筛选入口，并补充锁定文档、外部修改冲突、标注列表和 AI 修改记录的界面状态。
3. 将术语卡片的“在文档中查看”改为“查看术语”，并让卡片标题与实际悬停的术语一致。
