# 标注与术语

这一篇较长的文档用于展示正文标记、右侧标注位置栏、类型筛选和术语卡片。文档正文与标注数据分开放置。星图计划的项目快照包含两者。

## 一、为什么把说明写在正文之外

项目快照是整个文件夹的可复制状态，而不是某台电脑上的绝对路径。术语定义属于项目层级，所以多个文档可以共用同一个解释。把鼠标放在“项目快照”上，应该能看到一致的定义。

批注是一种讨论，不必改变正在写的句子。这里有一句需要讨论的原文：术语解释应在项目内复用。点击它附近的正文标记，可查看独立保存的批注说明。

文本可以继续编辑。标注保存了原句和周围语境，用来在正文变化后重新寻找位置。标注与待办任务项分开：一条标注可以指向句子中的短语，而任务项是 Markdown 自身的内容。

## 二、待办放在写作流程中

在正式发布之前，请确认发布窗口。这里的“待办”是对所选文字的标注，不是前一篇文档里的复选框。点击左下角“待办”可从项目角度浏览。

右侧的位置缩略图按原文中的大致位置显示彩色点。顶部的筛选入口可以单独隐藏或显示某种类型；它不会删除标注，也不会改变左下角的项目总数。

## 三、疑问留在句子旁

当写作规则还不确定时，可以先留下一个问题：这条规则是否需要例外。疑问标注有自己的颜色和说明，稍后可以编辑说明或删除标注；删除不会改动这句话。

上下文锚点保存所选文字的前后语境，用于定位重复出现的短语。这里的“上下文锚点”仍应出现术语卡片。

## 四、错误等待修正

为了演示错误标注，这里故意写错：示例金额写成了 1000 元。你可以先查看标注详情，再把正文改成正确金额，最后删除对应标注。

若直接把被标注的文字改掉，旧标注可能无法准确定位。此时项目标注列表会保留记录并提示重新定位，不应该把它强行画在错误位置。

## 五、术语出现位置例外

本段的上下文锚点特意关闭了自动解释。它仍是普通正文，项目术语列表里可以看到这一处例外并恢复解释。其他位置的同名词仍能显示术语卡片。

术语卡片中的“查看术语”会打开项目术语列表。术语可以在列表中编辑或删除；这不会把定义插进 Markdown 正文。
